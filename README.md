# 秦小皇音乐

一个**纯本地运行**的浏览器音乐播放器：不装软件、不注册账号、不上传任何文件，选择你电脑上的音乐文件夹即可开始听歌。

## 1. 解决什么问题

- 想听本地音乐，但不想安装臃肿的播放器、不想被联网推荐打扰
- 担心隐私：本应用**只读**你的音乐文件夹，不复制、不移动、不修改任何文件，所有数据（歌单、标签、封面、设置）只存在浏览器本地 IndexedDB 里
- 希望即开即用：一个静态网页 + 一个本地服务器脚本，双击就能跑

## 2. 主要功能

- **文件夹扫描**：递归扫描音乐文件夹，支持 `mp3 / flac / m4a / wav / ogg`，中文本地化自然排序（"第2首" 排在 "第10首" 前）
- **标签与封面**：自动解析五种格式的标签（标题/艺术家/专辑/封面），懒加载不卡顿；封面自动压缩存储
- **歌单管理**：勾选参与播放的歌曲、全选、行内编辑标题/艺术家/专辑（只改库里的显示值，不动文件）
- **播放引擎**：顺序 / 单曲循环 / 随机三种模式，上一首/下一首/播放暂停、进度拖拽、音量、静音；自动跳过无法播放的文件
- **键盘快捷键**：空格播放/暂停，方向键切歌/调音量等
- **持久化与续播**：歌单、勾选状态、编辑结果、音量、播放模式、上次播放位置全部本地保存，下次打开自动恢复
- **备份恢复**：一键导出备份 JSON（歌单 + 编辑 + 设置 + 续播点），换浏览器/重装后可导入恢复
- **双浏览器方案**：Chrome / Edge 用 File System Access API 记住文件夹授权；Firefox 用 `webkitdirectory` 选文件夹（重启浏览器后需重新选一次，浏览器限制）

## 3. 安装方法

无需安装依赖，只需要任意一个静态文件服务器（不能直接双击 `index.html`，浏览器安全策略要求 http 来源）。

使用项目自带的服务器脚本（Windows PowerShell）：

```powershell
powershell -File tools\server.ps1 -Port 8000 -Root .
```

然后在浏览器打开：

```
http://127.0.0.1:8000/
```

也可以用其他静态服务器，例如：

```powershell
npx serve .
python -m http.server 8000
```

**浏览器要求**：最新版 Microsoft Edge / Chrome（推荐，可记住文件夹授权），或 Firefox（可用，重启后需重选文件夹）。

## 4. 使用方法

1. 打开页面后点击 **「选择音乐文件夹」**，选中存放音乐的文件夹（只读访问）
2. 应用自动扫描并列出歌曲，标签和封面会在后台逐步补全
3. 双击歌曲或点击底部 ▶ 开始播放；勾选多首后点 **「播放选中」** 只播选中的
4. 底部播放栏可切歌、拖进度、调音量；点模式按钮切换 顺序 / 单曲 / 随机
5. 右键或双击行内字段可 **编辑** 标题 / 艺术家 / 专辑（不影响原文件）
6. 顶部菜单：
   - **更换音乐文件夹** / **重新扫描**：文件夹内容变动后刷新
   - **导出备份…**：下载 `backup-*.json`
   - **导入备份…**：选择之前的备份文件恢复
   - **数据说明**：查看数据存储与权限说明
7. Chrome / Edge 完全重启浏览器后，如顶部出现黄色提示条，点 **「点此允许」** 一次即可；Firefox 重启后需重新选择文件夹

## 5. 输入输出示例

**输入：音乐文件夹**

```
我的音乐/
├── 周杰伦 - 晴天.mp3
├── 专辑A/
│   ├── 01 序曲.flac
│   └── 02 主题曲.m4a
└── live/
    └── 演唱会录音.wav
```

**输出：歌单列表**（扫描后页面显示）

| 勾选 | 标题 | 艺术家 | 专辑 | 时长 |
|------|------|--------|------|------|
| ☑ | 晴天 | 周杰伦 | 叶惠美 | 4:29 |
| ☑ | 01 序曲 | （未知） | 专辑A | 1:52 |
| ☑ | 02 主题曲 | （未知） | 专辑A | 3:40 |
| ☑ | 演唱会录音 | （未知） | live | 58:12 |

**输出：导出备份文件 `backup-20261012.json`**（结构示例）

```json
{
  "version": 1,
  "exportedAt": "2026-10-12T08:00:00.000Z",
  "songs": [
    {
      "id": "周杰伦 - 晴天.mp3",
      "fileName": "周杰伦 - 晴天.mp3",
      "title": "晴天",
      "artist": "周杰伦",
      "album": "叶惠美",
      "checked": true
    }
  ],
  "settings": { "mode": "sequence", "volume": 0.8, "muted": false },
  "lastPlay": { "songId": "周杰伦 - 晴天.mp3", "position": 63.2 }
}
```

导入该文件即可恢复勾选、编辑结果、设置和续播位置。

## 项目结构

```
├── index.html            # 单页入口
├── assets/css/style.css  # 全部样式（深色 + 暖橙主题）
├── assets/js/            # 原生 JS，经典脚本 + 全局命名空间 QM
│   ├── compat.js         # 浏览器能力检测
│   ├── fs-access.js      # 文件夹访问（FSA + webkitdirectory 双后端）
│   ├── scanner.js        # 两阶段扫描与标签懒解析
│   ├── metadata.js       # 五格式标签/封面解析
│   ├── player.js         # 播放引擎
│   ├── db.js             # IndexedDB 持久化
│   ├── backup.js         # 备份导出/导入
│   └── ui/               # 歌单、播放栏、弹层等界面模块
├── tools/server.ps1      # 本地静态服务器
└── tests/                # M0-M6 自动化测试（qtest 框架）
```
